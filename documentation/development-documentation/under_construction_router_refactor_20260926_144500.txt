Change: Refactor routes/index.js
Date: 2026-09-26 14:45:00

Explanation:
- Removed duplicate mounting of formsRouter under both \'/forms\' and \'/api/forms\'.
- Grouped all API routes under the \'/api\' prefix for a cleaner public surface.
- Added an optional 404 handler to render a friendly 404 page.
- Added section comments for clarity and maintainability.
- Updated comments to describe the purpose of each section.

## Table of changes

| Old | New | Why |
|-----|-----|-----|
| `router.use("/forms", formsRouter);` and `router.use("/api/forms", formsRouter);` | Only `router.use("/api/forms", formsRouter);` | Avoids duplicate mounts; the API is now the single point of entry for forms. |
| No grouping of API routes | All APIs under `/api` | Keeps public surface clean; easier to discover new endpoints. |
| No 404 handler | Added catch-all route | Improves UX for unknown URLs. |
| Inline comments | Structured sections | Easier to read and maintain. |
